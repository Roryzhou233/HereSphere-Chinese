# HereSphere 简体中文补丁

适用于本机当前安装的 HereSphere 0.11.4（Windows / UE4.25）版本。安装器会校验原程序和原始 PAK 的 SHA-256；其他构建版本会停止安装。

## 本次修复

- 补齐投影、立体模式、宽高比、屏幕朝向、全局设置、背景及遮罩等下拉菜单的常用选项。
- 补齐字幕弹窗：启用、使用自动对焦、自动对焦缩放、固定距离、俯仰（位置）、屏幕深度偏移及相应提示。
- 扩充其他弹窗、设置项、提示和用户指南。
- 补齐四类按键绑定中的操作名称，以及体感控制器、手柄、键盘、鼠标按键的常用显示名称。字母键、型号和部分技术缩写保留原文。

资源包修改了 113 个 UI 资源中的 2379 处文字，并翻译了 359 条说明表内容。动态下拉菜单与按键操作名称通过文字显示调用点处理，保留英文选项值、内部按键标识、匹配逻辑及存档格式。协议、第三方版权声明、产品名、用户文件名及部分技术缩写保留原文。尚不能保证所有运行场景均无英文。

## 安装

1. 完全退出 HereSphere。
2. 解压整个压缩包，保持文件在同一目录，双击 `Install.cmd`。
3. 安装器会读取 Steam 安装位置和游戏库配置，自动查找各磁盘上的 HereSphere；也能识别放在游戏根目录或其子目录中的补丁。
4. 找到多处安装时，输入相应编号；未找到时，粘贴或拖入包含 `HereSphere.exe` 的游戏根目录，按回车继续。直接回车取消。Steam 中右键游戏，选择“管理 → 浏览本地文件”可查看路径。
5. 提示安装校验成功后，从 Steam 正常启动即可。如遇访问被拒绝，以管理员身份运行 `Install.cmd`。

通常无需修改任何脚本。也可显式指定路径，支持中文、空格和方括号：

```cmd
Install.cmd -GameDir "D:\我的游戏\SteamLibrary\steamapps\common\HereSphere"
Uninstall.cmd -GameDir "D:\我的游戏\SteamLibrary\steamapps\common\HereSphere"
```

PowerShell 调用方式：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install-Chinese.ps1 -GameDir 'D:\SteamLibrary\steamapps\common\HereSphere'
```

**仅复制 PAK 无法汉化动态下拉选项，需使用安装器同时应用程序显示补丁。** 补丁不需要额外字体，不修改原始 PAK。

安装器支持从上一版汉化直接升级，原程序备份仍保留。分享时请发送完整压缩包；接收者的游戏构建版本仍需通过安装器校验。

## 中文编码

CMD 启动器使用纯 ASCII、CRLF 换行，并先切换到 UTF-8 代码页 65001；PowerShell 脚本使用 UTF-8 BOM，兼容 Windows 自带的 PowerShell 5.1，并设置控制台输入输出为 UTF-8。中文路径与提示已通过实际 CMD 调用测试。若旧终端字体缺少中文字形，可改用 Windows Terminal 或系统支持中文的字体。

## 卸载与恢复

退出软件后双击 `Uninstall.cmd`，目录识别与安装时相同。安装器将恢复备份的原程序并删除本版中文 PAK；备份仍保留。

原程序备份：

```text
HereSphere\Binaries\Win64\HereSphere-Win64-Shipping.exe.cn-original
```

也可手动将此备份复制为同目录的 `HereSphere-Win64-Shipping.exe`，并移除：

```text
HereSphere\Content\Paks\HereSphere_Chinese_P.pak
```

如果 Steam 已更新程序，卸载器会保留更新后的程序，避免用旧备份覆盖新版。更新软件前建议先卸载汉化；版本不匹配时不要强行应用本补丁。

## 文件与校验

- `HereSphere_Chinese_P.pak`：中文界面和说明资源。
- `native-section.bin`、`native-patch.json`：程序显示补丁数据与原版本校验信息，不包含完整游戏 EXE。
- `Install-Chinese.ps1`：安装与卸载逻辑。
- `Find-HereSphere.ps1`：Steam 多游戏库发现、安装目录校验与手动选择。
- `MenuStringTable.zh-CN.csv`：中文说明表，供查阅或后续维护。
- `build-report.json`：资源翻译数量及文件校验值。
